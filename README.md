# proyectos rueda libre y rueda nocturna

## descripcion

este repositorio contiene dos proyectos web desarrollados durante las actividades de desarrollo de software.

**rueda libre** es un sitio web creado para ofrecer alquiler de bicicletas y recorridos guiados por la ciudad de medellin. permite conocer los servicios, consultar las tarifas y realizar reservas.

**rueda nocturna** es una campaña para promocionar recorridos en bicicleta por medellin durante la noche.

## tecnologias utilizadas

### proyecto rueda libre
- html5
- css3
- bootstrap 5
- bootstrap icons
- javascript

### proyecto rueda nocturna
- html5
- tailwind css 4
- javascript

## funcionalidades de rueda libre

- pagina de inicio con informacion del proyecto
- tarjetas para mostrar los servicios
- seccion de tarifas y rutas
- carrusel de imagenes
- formulario de reservas con validacion
- menu de navegacion
- diseño adaptable a celulares, tabletas y computadores
- boton de contacto por whatsapp
- estilos personalizados con css

## funcionalidades de rueda nocturna

- pagina principal de la campaña
- presentacion de tres rutas nocturnas
- tarjetas con informacion de cada recorrido
- seccion de como funciona
- formulario o seccion de inscripcion
- diseño responsive
- estilos personalizados con tailwind css
- modo oscuro

## componentes y herramientas de bootstrap

en rueda libre se trabajaron componentes y herramientas de bootstrap como:

- sistema de grid
- navbar y navegacion
- cards
- carrusel
- formularios
- validacion de formularios
- botones
- alertas
- utilidades responsive

## organizacion del repositorio

- `index.html`: pagina principal de rueda libre
- `paginas/tarifas.html`: informacion de tarifas y rutas
- `paginas/reservas.html`: formulario de reservas
- `css/styles.css`: estilos personalizados de rueda libre
- `img/`: imagenes del proyecto
- `nocturno/`: proyecto desarrollado con tailwind css
- `bitacora.txt`: registro del desarrollo de los mini retos
